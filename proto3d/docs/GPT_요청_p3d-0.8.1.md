## 4. 요청 — 기획

1. **지상의 발 지정 동작의 이름과 기본 키.** 지금 `footGround` = X(누른 채 클릭). 사용자 의견 ⑦("손으로 잡지 않고는 낮은 턱에 발을 먼저 올릴 수 없다")을 살리려고 남겼다. 이 동작을 둘지, 둔다면 키를 무엇으로 할지.
2. **0.8.0에서 넣은 몸의 층 가운데 뺄 것이 있는지.** 특히 (a) 한 발만 디딜 때 놓인 다리를 옆으로 뻗는 모양(효과 없음) (b) 흔들기 입력에 다리가 먼저 가는 모양(힘은 근사) (c) 가만히 있을 때 머리가 둘러보는 것. 셋 다 "모양만"이다.
3. **W를 누를 때 높이 디딘 발 쪽으로 엉덩이가 가는 것**을 유지할지(14.2의 켬·끔 비교: 켬은 턱 F를 잡고 끔은 못 잡는다). "현재 지지가 허용하는 체중 이동"으로 보고 켜 두었다.
4. **다음 한 장면**을 무엇으로 할지. 후보: (a) 같은 장면에서 몸이 옆으로 도는 것까지 (b) 발판 도약 → 다시 잡기 → 받기 (c) 자유 다리 균형의 작은 진단. 개발 쪽 의견: (a) → (c) → (b).
5. 벽 딛기 실험 옵션을 남겨 둘지(비교용), 발 보조 안으로 합칠지.
