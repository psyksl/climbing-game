## 2. 숨기지 않는 것

1. **0.9.0 보고의 "영상에서 본 것"은 0.1~0.33초 간격의 장면이었고, 0.06초짜리 튐을 놓쳤다.** 사용자가 찾았다. 디딘 다리가 초속 300°를 넘는 구간: 0.8.8 24개(가장 빠를 때 517°/s) → **0.9.0 58개(1,683°/s)** → 0.9.1 0개(15장면, 걸음마다). 0.8.8에도 같은 종류가 있었고 0.9.0이 키웠다.
2. 원인: 올라서며 엉덩이가 벽 10cm까지 오면 무릎 후보가 모두 벽 5cm 안이 되고, 후보가 걸음마다 바뀌어 빠른 빼내기(초속 26라디안)가 무릎을 반대쪽으로 돌렸다. 무릎 방향을 연속된 값(벽까지의 실제 거리 + 지금 쪽과의 차이)으로 고르고, 디딘 무릎의 도는 빠르기를 3.5 / 8라디안으로 낮췄다.

4. 같은 방법으로 찾았지만 고치지 않은 것: "놓았던 손을 되돌려 잡기"의 팔 튐(오른팔뚝 초속 3,734°, 0.8.8에도 2,610°) — 손이 다른 손 바로 옆으로 갈 때 팔꿈치가 얼굴 앞을 넘어간다.
