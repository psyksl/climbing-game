## 3. 숨기지 않는 것

1. **두 팔이 서로를 지나가는 걸음이 남아 있다.** 교차 일곱 구간에서 두 팔뚝의 줄기가 4cm 안인 걸음: 108 → 41. 뻗는 동안 1.2~1.6cm까지 가까워진다. 엇갈려 잡은 채로는 5.2~6.3cm(겉은 조금 겹친다). 통과·실패가 아니라 자료로 적었다.
2. 겹침의 기준은 팔뚝의 **줄기**(가운데 선)다. 겉면으로 재면 팔을 몸 옆에 붙인 보통 자세도 걸린다(팔 통과 가슴 상자가 어깨에서 맞닿게 그려져 있다). 손목 표면은 최대 0.9cm 몸에 든다(기준 1.5cm).
3. 몸이 벽에 붙어 있으면 가슴과 벽 사이(6.5cm)로는 손이 지나가지 못한다 — 위로 돌아가거나 멈춘다("제 몸에 가려 닿지 않음", 임시 문구). 뻗는 손을 위해 몸이 뒤로 비키는 것은 넣지 않았다(잡은 팔과 머리 사이에만 있다).
4. **알려진 실패(그대로)**: 한 걸음 회전 튐(기준 12°) 자작 17.7°·29회, 캡처 25.6°·86회. 캡처에서 뛰어 잡은 직후 왼 정강이가 벽에 3걸음. 벽 딛기 실험(기본 끔)의 실제 입력 항목 — BROWSER_WALLREST.
5. 제자리 점프(캡처)의 가장 높은 곳 근처 다리 길이비는 0.46 / 0.42로 자작(0.69)보다 무릎을 더 접는다 — 그대로다.
6. 0.8.4와의 대조는 "새 시험을 0.8.4 소스에 돌린 것"이다(`results/wall_check_새시험을_0.8.4_소스에.txt`).
