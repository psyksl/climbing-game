# 등반 동작 참고 자료 (2026-11-19, 사용자가 준 Mixamo 등반·매달리기 동작에서 뽑음)

사용자 지시: "2D를 보면 다리·팔·골반·몸통 등 여러 동작에서 어색한 부분이 있었다. 참고할 수 있으면 참고해서 개선하는 데 쓰라고 보낸 것이다."

## 무엇을 했나

- 이름으로 등반·매달리기로 나눈 86개(좌우를 뒤집은 것 포함 파일 91개)를 묶음 11개로 나눠, **원본 뼈 자리**에서 장면마다 관절 각도·몸통 기울기·손발 간격·손발 옮기는 시간을 쟀습니다. 도구 `tools/climb_reference.mjs`, 결과 `results/climb_reference.json`(통계만. 동작 값은 없음).
- 받은 동작 223개를 전부 이 시제품 캐릭터로 옮겨 **동작 보기**(G 키)로 하나씩 볼 수 있게 했습니다(캡처 빌드에서만). p3d-0.4.0부터는 동작마다 지형 조각을 놓아 함께 보입니다(`동작_준비.md`).
- 조사한 범위와 한계
  - 이 동작들은 게임용 "턱 잡고 오르기·매달려 옮기기" 동작입니다. 암벽등반 기술(플래깅, 드롭 니, 발 바꾸기 등)을 담은 자료가 아닙니다. 쓸 수 있는 것은 **몸의 기본 움직임**(관절이 얼마나 굽는지, 몸통이 얼마나 기우는지, 손발을 어떤 순서·시간으로 옮기는지)입니다.
  - 한 사람(또는 소수)의 동작을 X Bot 뼈대에 얹은 값입니다. 사람 전체의 범위가 아닙니다.
  - 아래 범위는 5%~95% 값(가운데 값)입니다. "고관절 벌림"은 넓적다리가 수평에 가까우면 크게 나오는 단순한 측정이라 큰 값은 참고만 하세요.

## 2D에서 어색했던 것과 견주기 (개발 쪽 의견)

**읽는 법 (GPT의 p3d-0.4.0 검토로 고침)**: 아래 값은 **이 샘플에서 관찰한 경향**이고, 등반에서 허용되는 자세의 한계가 아닙니다. 쓰임은 "편한 기본 자세의 출발점"까지입니다.

## 쓰는 방법과 쓰지 않는 방법

- **쓴다**: 자세 풀이가 여러 해 가운데 고를 때의 기본값(편한 쪽으로 당기는 값)으로. 동작 보기에서 자세를 눈으로 견줄 때. 매달린 자세·발을 벽에 댄 자세의 처음 모양으로.
- **쓰지 않는다 ①**: 이 범위를 벗어났다는 이유로 접촉이나 자세를 거부하는 데. 허용 여부는 접촉·관절 가동 범위·몸 충돌·지지 가능성으로 판정한다.
- **쓰지 않는다 ②**: 등반 동작을 게임에서 그대로 트는 데. 정해진 벽에서 정해진 거리만큼 가는 동작이라, 틀면 물리가 허용하지 않는 도달을 애니메이션이 성공시킨다.
- **점검에서의 쓰임**: 3D에서도 자세를 잴 때 이 범위를 "기본 자세에서 얼마나 벗어났는지"의 참고 눈금으로 적는다. 합격·불합격 기준으로 쓰지 않는다.
- 손발이 닿는지·버티는지는 계속 물리가 정한다. 캡처는 "그 손발 자리에서 몸이 어떤 모양이면 편한가"에 답한다.
