# 등반 동작 참고 자료 (2026-11-19, 사용자가 준 Mixamo 등반·매달리기 동작에서 뽑음)

사용자 지시: "2D를 보면 다리·팔·골반·몸통 등 여러 동작에서 어색한 부분이 있었다. 참고할 수 있으면 참고해서 개선하는 데 쓰라고 보낸 것이다."

## 무엇을 했나

- 이름으로 등반·매달리기로 나눈 86개(좌우를 뒤집은 것 포함 파일 91개)를 묶음 11개로 나눠, **원본 뼈 자리**에서 장면마다 관절 각도·몸통 기울기·손발 간격·손발 옮기는 시간을 쟀습니다. 도구 `tools/climb_reference.mjs`, 결과 `results/climb_reference.json`(통계만. 동작 값은 없음).
- 받은 동작 223개를 전부 이 시제품 캐릭터로 옮겨 **동작 보기**(G 키)로 하나씩 볼 수 있게 했습니다(캡처 빌드에서만). p3d-0.4.0부터는 동작마다 지형 조각을 놓아 함께 보입니다(`동작_준비.md`).
- 조사한 범위와 한계
  - 이 동작들은 게임용 "턱 잡고 오르기·매달려 옮기기" 동작입니다. 암벽등반 기술(플래깅, 드롭 니, 발 바꾸기 등)을 담은 자료가 아닙니다. 쓸 수 있는 것은 **몸의 기본 움직임**(관절이 얼마나 굽는지, 몸통이 얼마나 기우는지, 손발을 어떤 순서·시간으로 옮기는지)입니다.
  - 한 사람(또는 소수)의 동작을 X Bot 뼈대에 얹은 값입니다. 사람 전체의 범위가 아닙니다.
  - 아래 범위는 5%~95% 값(가운데 값)입니다. "고관절 벌림"은 넓적다리가 수평에 가까우면 크게 나오는 단순한 측정이라 큰 값은 참고만 하세요.

## 2D에서 어색했던 것과 견주기 (개발 쪽 의견)

| 2D에서 나온 문제 (CLAUDE.md의 기록) | 캡처 동작에서 본 값 | W2(3D 벽 접촉)에서 이렇게 쓴다 |
|---|---|---|
| 매달려 흔들 때 몸통이 79°까지 기울었다. 버팀 한계를 45°로 두었다(`TILT_MAX`) | 매달려 있기·시미·벽 오르기에서 몸통 좌우 기울기는 가운데 3~11°, 95%가 17° 아래. 뛰어 옮길 때(홉)만 25° | 몸통 좌우 기울기의 **보통 범위를 15~20°**로 잡고, 그보다 기우는 것은 뛰어 옮기기 같은 큰 동작에서만 허용. 45°는 한계로는 너무 넓다 |
| 뒤틀린 몸(골반과 가슴이 따로 돈다) | 골반·가슴 비틀림은 가운데 3~8°, 벽을 타고 오를 때만 95%가 31° | 비틀림은 **손발을 멀리 뻗는 순간에만** 생기게 하고 보통은 10° 안. 가슴·골반을 나눌 때(4단계의 과제)의 목표 값 |
| 무릎이 늘 옆으로 벌어져 <> 모양 | 무릎이 향한 쪽은 가운데 17~42°(0 = 벽 쪽). 옆으로 가장 많이 가는 시미도 95%가 59° | 무릎은 **벽 쪽에서 20~40° 바깥**이 기본. 완전히 옆(90°)은 홉·내려오기의 순간에만. 2D v0.16.0에서 잡은 방향(보통 벽 쪽, 개구리 자세에서만 옆)과 같은 쪽이고, 기본 값은 조금 더 바깥이다 |

## 쓰는 방법과 쓰지 않는 방법

- **쓴다**: 위 범위를 자세 풀이의 "보통 범위"와 점검 기준으로(2D의 `pose_audit.js`처럼 3D에서도 전후를 잰다). 동작 보기에서 자세를 눈으로 견준다. 매달린 자세·발을 벽에 댄 자세의 처음 모양을 캡처 자세에서 가져온다.
- **쓰지 않는다**: 등반 동작을 게임에서 그대로 틀지 않는다. 정해진 벽에서 정해진 거리만큼 가는 동작이라, 틀면 물리가 허용하지 않는 도달을 애니메이션이 성공시킨다.
- 손발이 닿는지·버티는지는 계속 물리가 정한다. 캡처는 "그 손발 자리에서 몸이 어떤 모양이어야 사람 같은가"에 답한다.
