## 3. 숨기지 않는 것

1. **몸의 연결은 풀리지 않았다.** 윗몸의 각도만으로는 어깨가 목표 쪽으로 더 가지 못한다(재 봄). 몸의 자리가 움직여야 하는데 그것은 지금 플레이어의 조작(W·A·D)이고, 자동으로 넣으면 닿는 거리가 는다 — 기획 결정이라 넣지 않았다.
2. 닿는 순간의 손 속도는 초속 3.2 → **1.1m**다. 0.5m까지 줄였더니 놓았던 손을 되돌려 잡지 못하는 회귀가 생겼고(수정 후 영상의 로그에서 찾았다), 원인 둘 가운데 하나는 고쳤지만 다른 하나(턱 가까이에서 너무 느린 손은 턱을 돌아가지 못한다) 때문에 1.1에서 멈췄다.
3. 걸리는 시간은 거의 그대로다(막힘 1.43 → 1.40초, 잡기 0.38 → 0.44초). 바뀐 것은 그 안의 빠르기 모양이다. 다 편 채 기다리는 0.22~0.27초(`TRY_T`)는 그대로다.
4. 잡았다가 0.74초 뒤 놓치는 것, 닭 날개 팔, 다리 엇갈림, 발 보조가 두 발을 모으는 것, 놓고 떨어질 때의 자세, 몸의 빠르기(초속 0.5m)는 손대지 않았다.
5. 사용자 PC의 fps와 버린 시간은 모른다. 영상(초당 30장)으로는 "적어도 30"까지만 말할 수 있다.
6. 영상에서 개발 쪽이 직접 본 것(21.6절. 정지 장면을 나란히 본 것이며 **시각 품질의 판정이 아니다**): 손이 순간이동하듯 올라가지 않고 내려오는 팔이 얼굴 앞을 가로지르지 않는다. 그러나 **뻗고 돌아오는 내내 몸통·골반·다리의 그림이 똑같다**(전후 같음). 복귀가 떠날 때 0.1~0.2초 굼떠 보일 수 있고 팔이 옆으로 벌어져 어색할 수 있다 — "슬로 모션 같다"는 의견과 맞설 수 있어 사용자 판단을 기다린다.
7. 알려진 실패 그대로: 한 걸음 회전 튐(기준 12°) 자작 18.7°·16회, 캡처 18.7°·65회(0.8.7: 17.7°·29회, 25.6°·86회) · 캡처에서 뛰어 잡은 직후 왼 정강이가 벽에 3걸음 · 벽 딛기 실험(기본 끔)의 실제 입력 항목(여섯 번 가운데 한 번, 캡처 빌드) · `demo_check`의 손 거리 3개
