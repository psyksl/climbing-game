## 3. 숨기지 않는 것

1. **발이 닿지 않는 한 손 매달림의 사례는 "다른 팔에 막힘"이 아니라 "닿지 않는 거리"로 끝났다**(턱 B에서 오른손을 놓고 4초 뒤 왼손 15cm 너머로. 자작 7cm · 캡처 15cm 모자람). 뻗는 3.5초 동안 발이 디딘 걸음 0, 발의 가장 낮은 높이 바닥 위 19cm, 잡은 왼손 1.00배로 유지. 따라서 확인된 것은 "공중 한 손 매달림에서 교차를 시도해 거부되는 동안 잡은 손이 유지된다"까지이고, **공중 한 손 매달림에서 팔–팔 막힘이 작동하는 것을 본 사례는 아직 없다.** 자작에서 뻗는 동안의 팔–팔 겹침(대리 형상)은 1.57cm였다(여유 1.2cm 초과, 시험 기준 1.6cm 바로 아래. 통과·실패로 세지 않는 자료다).
2. **앞 판의 설명 하나를 거둔다**: "되돌리는 자리 -1.2는 캡처 모션에서 2cm 모자랐다"는 작업 중간 상태에서 본 것이고 최종 소스로 다시 재지 않고 적었다. 0.8.6의 최종 소스와 0.8.7에서 -1.20은 두 모션 모두 잡힌다(독립 재실행과 같다). 자리를 바꿀 까닭이 최종 빌드에는 없었다.
