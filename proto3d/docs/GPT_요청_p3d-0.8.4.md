## 3. 숨기지 않는 것

1. **앞 판의 설명 둘이 틀렸다.** ① "한계는 축 방향 몫" → 실제 원인은 앞 걸음과의 섞기, 표시의 고름, 그리고 손 하중에 든 "편 팔 버팀". ② "턱 F의 0.55초는 팔꿈치가 도는 동안의 기다림" → 우회는 0.017초였고 0.33초는 닿는 거리를 기다린 것(윗몸이 목표 반대쪽으로 기울어서).
2. **뻗는 팔뚝이 제 머리·가슴을 지나간다**: 중심선 기준 3,668걸음 가운데 자작 123걸음·캡처 155걸음, 가장 깊이 7.6cm. 주로 손 조작 2로 손을 끌어 몸 앞을 가로지를 때. 제 몸을 장애물로 넣는 시도는 더 나빠져 되돌렸다.
3. 한 걸음 튐(12° 기준): 자작은 줄었고(72 → 30회) **캡처는 늘었다(58 → 86회)**. 늘어난 것은 발이 바닥에서 떨어지는 걸음의 정강이 12.4°.
4. 되돌린 시도 넷: 엉덩이의 앞뒤 치우침까지 없애기(앞발이 벽에 6cm), 아랫몸 섞기(착지 24° 튐), 무릎 빠른 돌림 유지(효과 없음), 제 몸 장애물(위 2).
