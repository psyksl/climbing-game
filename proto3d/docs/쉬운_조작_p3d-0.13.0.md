# 쉬운 조작 (p3d-0.13.0)

상태: **기술 반영, 시각/사람 확인 대기.** 아래 수치는 모두 **스크립트 입력(사람 손 아님)**, 캡처 동작(`MODE=clip`), 새 자세 방식(fb), 잡기 보정·자세 보조·발 보조 켬으로 잰 것이다. 사람이 쉬워졌다고 느끼는지는 재지 못했다.

사용자 지시(2026-11-25): "연습용 벽 정도는 대충 막 해도 될 정도여야 한다. 어려움은 조작이 아니라 맵에 둔다" → 후보 ①→②→③을 순서대로 넣고 같은 측정으로 전후를 견준다.

## 1. 넣은 것 (옵션 하나: L 키 "쉬운 조작", 화면 기본 켬 · 시험 기본 끔)

| | 무엇 | 끄는 스위치 |
|---|---|---|
| ① 조준 맞춤 | 누른 자리에 잡을 턱이 없으면, 화면에서(시선에 수직으로 잰 거리) 26cm 안의 가장 가까운 턱 모서리로 손을 보낸다(`aimGrip`). 정확히 턱을 누른 경우는 전과 같다. 미리보기도 같은 자리를 보인다. **손만**(발은 아님) | `NOAIMSNAP` |
| ② 예약 | 가만히 선 채 40cm 넘게 모자란 턱을 누르면, 손을 놓지 않고 2초 동안 기다린다. 그사이 뛰기 시작하거나 닿게 되면 그때 손을 보낸다(같은 명령·같은 판정). 2초가 지나면 원래 까닭으로 거부한다. 40cm 안으로 모자라면 전처럼 바로 뻗고, 뻗다가 거리 때문에 거부되면 그때 예약으로 남는다 | `NOARMREACH` |
| ③ 자동 몸 맞추기 | 뻗은 손이 30cm 안으로 모자란 채 멈췄고 플레이어의 몸 입력이 없으면, 거부하기 전에 최대 1.2초 동안 W(또는 A·D 한쪽)를 누른 것과 같은 입력을 넣는다. 0.35초 동안 가까워지지 않으면 그만둔다. **닿는 거리가 실제로 느는 보조다** | `NOAUTOBODY` |

- 물리·판정은 바꾸지 않았다. ①은 손을 보낼 자리만, ②는 보내는 때만, ③은 몸 입력만 바꾼다.
- 40cm·30cm·26cm·2초·1.2초는 모두 **실험값**이다.
- 화면 문구("◌ 예약: 닿으면 잡음 — 다가가거나 뛰기", "몸을 옮겨 닿는 중", "쉬운 조작 켬/끔")는 **임시**다(GPT 디자인 요청 대상).

## 3. 고치는 중에 찾은 것

첫 구현의 측정은 합계가 ①만 켠 것과 같았고(337), **끔에서 되던 5가지가 안 됐다.** 걸음마다 따라가(`test/easy_trace.mjs`) 찾은 까닭:

- **미리보기의 "몇 cm 모자람"은 실제보다 18~34cm 크다.** 손을 잡은 채의 어깨로 재는데, 손을 놓고 뻗으면 윗몸이 목표 쪽으로 돌고 기울어 그만큼 더 닿는다(3단계: 18cm 모자람 → 0.33초 뒤 잡음. 5단계: 34cm 모자람 → 0.46초 뒤 잡음). 첫 구현은 모자란 손을 모두 예약으로 돌려, 바로 잡히던 손이 2초 기다리다 거부됐다. → 40cm 안은 전처럼 바로 뻗는다.
  - 이것은 쉬운 조작과 따로 **화면의 미리보기가 "닿지 않음"이라고 하는 자리를 눌러 보면 잡히는 일이 있다**는 뜻이다(고치지 않음, 5절).
- 자동 몸 맞추기를 예약된 손(잡은 채)에 걸었더니, 위의 과장된 값을 보고 필요 없는 때에 W+D를 2초 눌러 한 발로 선 몸이 옆으로 14cm 흔들렸다. → 뻗은 손이 멈춘 뒤에만, 한쪽 방향만.
- 잡은 팔이 벽·턱을 스쳐도 놓치지 않는 시간을 0.15 → 0.6초로 늘렸던 것은 뺐다(관통을 더 오래 두는 것이고, 고친 뒤에는 경로에 필요 없었다).
