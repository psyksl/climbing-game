## 3. 숨기지 않는 것

1. **닿는 거리가 달라졌다.** 사용자 장면(왼발을 교차로 발판에 → W → 오른손을 턱 F로)에서 잡히기 시작하는 W가 80 → 50걸음(0.25초 일찍), 같은 W 45걸음에서 8cm 모자람 → 2cm 모자람. 자세만의 몫은 약 1cm이고 나머지는 **엉덩이가 디딘 발 위로 가서 같은 W로 몸이 더 올라가는 것**이다(몸의 기준 자리를 직접 옮기지 않았다). 바닥에 두 발로 선 자세는 변화 없음. 층을 끄면(O) 0.8.8과 같다.
2. **손을 뻗는 동안의 몸은 여전히 거의 움직이지 않는다**(가슴 2.0cm, 골반 1.1cm). 이번 층은 발을 올리고 디디고 올라서는 구간에서 일한다.

5. 취소·거부된 발은 바닥으로 돌아가지 않고 떠 있다(0.8.8과 같음).
