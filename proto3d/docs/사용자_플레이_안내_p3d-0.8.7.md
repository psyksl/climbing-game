# 5~10분 플레이 안내 — p3d-0.8.7 (2026-11-21)

새 기능 추가는 멈췄다. 이 판으로 사람이 직접 해 본 의견을 받는다. 지금까지의 시험·영상은 모두 **스크립트 입력(사람 손 아님)** 이다.
성공한 것만이 아니라 **실패한 것, 헷갈린 것, 어색해 보인 것**이 필요하다. 점수나 "조금 나아짐" 한 줄이 아니라 아래 5절처럼 적어 주면 된다.

## 1. 시작 (콘솔 입력 없음)

1. `climb3d_mocap.html`(캡처 동작) 또는 `climb3d.html`(자작 동작)을 브라우저로 연다.
2. **T** 를 누른다 → 작은 벽 앞에서 시작한다. (**R** = 처음 자리로)
3. 화면 **왼쪽 위** 칸의 넷째 줄(작은 글씨)을 본다: `손 조작 1 · 눌러 보내기   발 보조 켬/끔`
   - **발 보조가 "켬"이면 F를 한 번 눌러 "끔"으로** 바꾼다. (지난번 설정을 브라우저가 기억한다 — 켜져 있을 수 있다)
   - `실험: 벽 딛기 켬`이 보이면 **J** 를 눌러 끈다. (보이지 않으면 꺼져 있는 것이다)
   - 주소 끝에 `?manual`을 붙여 열면 두 가지가 꺼진 채 시작한다(저장된 설정은 바꾸지 않는다).
4. 손 조작은 **1(눌러 보내기)** 로 먼저 하고, 익숙해지면 **H** 로 **2(누르는 동안 뻗고 떼면 잡기)** 도 해 본다. **어느 쪽으로 시작했는지 적어 준다.**

설정이 다르면 느낌이 달라진다. 발 보조가 켜져 있으면 발이 저절로 발판을 찾아가므로, 그 차이를 모션이나 손맛의 차이로 읽지 않게 위 설정을 먼저 맞춘다.

## 2. 조작 (기본 키. K = 조작표 모두 보기)

| 하는 일 | 키 |
|---|---|
| 왼손 / 오른손을 겨눈 턱으로 | 마우스 왼쪽 / 오른쪽 단추 (땅에 서 있을 때 오른쪽은 **짧게** 누른다 — 길게 누르면 시점 돌리기) |
| 발을 보내기 | **Shift를 누른 채** 왼쪽 / 오른쪽 단추 (땅에서는 **X를 누른 채**) |
| 손 놓기 | Q(왼손) / E(오른손). 발은 Shift + Q / E |
| 몸 옮기기(벽에서) | W 위 · S 아래 · A / D 좌우(화면 기준) |
| 뛰기 | Space(오래 누르면 높이. 벽에서는 W·A·S·D로 방향) |
| 시점 | 땅: 오른쪽 단추를 누른 채 끌기 · 벽: V(시점 보기 모드 — 조작이 멈춘다) → 끌기 → V |
| 손 조작 1 ↔ 2 | H |
| 발 보조 켬·끔 | F |

## 3. 해 볼 것 (순서는 자유. 다 하지 않아도 된다)

1. **턱 A**(T로 시작하면 바로 앞 머리 위에 있는, 서서 닿는 턱)를 두 손으로 잡는다. 원하는 손이 원하는 곳으로 가는가. (잡으면 왼쪽 위 칸에 `왼손 잡음(턱 A)`처럼 턱 이름이 나온다)
2. 한 손을 다른 손 **너머로 엇갈려** 잡아 본다(예: 오른손을 잡은 채 왼손을 오른손의 오른쪽으로). 다시 되돌려 본다.
3. 오른쪽 아래의 **낮은 발판**(무릎 높이의 좁은 턱)에 **발을 골라** 올리고(Shift + 단추), W로 올라서서 턱 A의 오른쪽 위에 있는 **턱 F**를 잡아 본다. 발을 바꿔서도 해 본다.
4. 일부러 **막히는 것**을 해 본다: 턱 A를 두 손으로 잡고 W로 올라갔다가 오른손을 놓고(E), 오른손을 왼손 너머 왼쪽으로 보낸다. `다른 팔에 막혀 닿지 않음`이나 `닿지 않음`이 나올 수 있다.
   - 그 뒤 **다시 시작하지 않고** 다른 길을 찾아본다(다른 턱, 발 디딤, 몸 옮기기).
   - 스크립트 입력으로 확인된 길이 하나 있다: 오른손을 턱 A의 엇갈리지 않는 자리로 다시 잡기 → 오른발을 낮은 발판에 → W → 오른손으로 턱 F. **이 길을 사람이 쉽게 찾는다는 뜻은 아니고, 자세만 바꾸면 같은 목표가 반드시 잡힌다는 뜻도 아니다**(발을 디디고 올라선 뒤 같은 목표를 다시 겨눈 스크립트 시도는 자작 동작에서는 거부됐고 캡처 동작에서는 잡혔다 — 조건에 따라 갈린다).
5. 더 오른쪽의 높은 **턱 B**(서서는 닿지 않는다)로 뛰어 잡아 본다(턱 밑으로 걸어가 Space를 누르며 두 손을 보낸다).

## 4. 볼 것

- **원하는 손발 선택**: 설명을 다시 읽지 않고 원하는 손·발을 골랐는가. 엉뚱한 팔다리가 움직였는가.
- **교차의 자연스러움**: 엇갈릴 때 손이 의도와 다른 쪽으로 돌아가는가(지금은 늘 잡은 팔의 밑, 벽 쪽으로 돌아 들어간다), 필요 이상 기다리는가, 몸이 끌려가는가. 가슴이 돌아가는 모양이 어색한가. 손 조작 2에서 목표를 바꿨을 때 전에 돌던 쪽에 갇히는가.
- **막힘의 이해와 대안**: 왜 막혔는지 화면을 보고 알았는가. 다시 시작하지 않고 다른 턱·발·몸 조작으로 이어 갈 수 있었는가.
- **발·체중 이동의 공략성**: 어느 발을 어디에 두느냐, 몸을 어느 쪽으로 옮기느냐가 결과를 가르는 것으로 느껴지는가.
- **점프·잡기**: 누르는 즉시 힘을 쓰는 느낌이 있는가. 성공했더라도 뚝 끊기거나 종이 인형처럼 보인 순간.

## 5. 적는 방법

한 가지마다 다섯 줄이면 충분하다. 화면 녹화(실제 입력이 보이면 더 좋다)가 있으면 그 구간을 알려 준다.

```
설정: 손 조작 1 / 발 보조 끔 / 벽 딛기 끔 / 캡처 빌드
하려던 것:
예상한 것:
실제로 일어난 것:
다시 해 본 방법과 결과:
(설명을 얼마나 읽었는지·들었는지)
```

## 6. 알고 있는 것 (플레이 중에 보여도 새 결함이 아니다)

- 팔다리가 한 걸음 사이에 튀는 순간이 있다(손을 놓거나 미끄러질 때).
- 캡처 동작에서 뛰어 잡은 직후 정강이가 벽에 잠깐 들어간다.
- 점프하면 공중에서 무릎을 접은 자세로 올라간다.
- 벽 딛기(J)는 실험이고 기본 끔이다. 켜면 잘 안 될 수 있다.
- 팔을 다 편 한 손 자세에서의 교차는 지금 막힌다("사람에게 불가능"이 아니라 지금 몸 모델에서 길을 찾지 못하는 것이다). 턱 B에 한 손으로 매달린 채 다른 손을 너머로 보내는 것도 지금은 잡히는 거리가 없다(멀면 "닿지 않음", 가까우면 "다른 팔에 막혀 닿지 않음").
- 턱 위로 올라서기(맨틀), 코스, 키 설정 화면은 없다.
