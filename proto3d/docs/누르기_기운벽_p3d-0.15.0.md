# 누르기와 기운 벽 (p3d-0.15.0)

상태: **기술 반영, 시각/사람 확인 대기.** 수치는 모두 **스크립트 입력(시험 봇, 사람 손 아님)**, 캡처 동작, 화면 기본 설정(새 자세·잡기 보정·자세 보조·발 보조·쉬운 조작 켬)으로 잰 것이다.

사용자 지시(2026-11-26): 클라이밍장 결과의 두 가지 — 누르기(낮은 손 위로 몸 올리기)와 기운 벽(오버행·슬랩) — "둘 다 진행해".

## 1. 누르기 (옵션 P, 화면 켬 · 시험 끔, 전신 자세 풀이에서만)

발판을 디디고 오를 때 낮은 손을 놓지 않고 몸이 그 손 위로 올라간다(당기는 손이 누르는 손이 된다).

- 전에 막던 것 셋을 누르기에서는 쓰지 않는다: ① 곧게 선 어깨가 가장 낮은 손보다 16cm 아래에서 오르기를 멈춤(`FOLD_GAP`) ② "몸이 손을 지나 올라가 놓음" ③ 전신 자세 풀이가 어깨를 손 아래에 두려고 가슴을 젖힘.
- 어깨가 손보다 위(어깨 → 손이 아래로 25% 넘게 기움)면 그 팔은 **미는** 힘을 낸다(몸무게의 0.55배까지, 미는 방향이 위에서 50° 안일 때만 버틴다). 당기는 팔은 버틸 수 있는 방향의 끝에 다가갈수록 힘을 줄인다(버티지 못할 방향으로는 당기지 않는다).
- 디딘 발판이 있을 때만이다. 오르는 높이는 어깨가 손보다 팔 길이의 90% 위까지.
- **하지 않은 것**: 발 없이 손으로만 눌러 올라서기(맨틀), **누르는 손의 모양**(손목 자리는 잡을 때 그대로다 — 손바닥을 윗면에 올려놓지 않는다. 그림으로 확인하지 않았다).
- 값(0.55배·25%·90%·접힘 26cm)은 모두 실험값. 끄는 스위치 `NOPRESS`.

### 결과

- 재기용 사다리(손 사이 40cm): 끔 = 둘째 손에서 47cm 모자람 → **켬 = 완등**. 45cm는 손이 아니라 발(45cm 위의 발판으로 "다리가 그렇게는 올라가지 않음")에서 멈춘다.
- 코스(대충 ±8cm, 씨앗 3, 같은 봇·같은 벽):

| 코스 | 누르기 끔 | 누르기 켬 |
|---|---|---|
| 초록(입문) | 2/3 | 2/3 |
| 노랑(기둥) | 1/3 | **3/3** |
| 분홍(모서리) | 2/3 | 1/3 |
| 보라(옆 벽) | 0/3 | 1/3 |
| 파랑(옆으로) | 0/3 | 1/3 |
| 빨강(42cm) | 0/3 | 0/3 |
| 검정(뛰어 잡기) | 2/3 | 1/3 |
| 연두(오버행 15°) | 1/3 | 1/3 |
| 갈색(오버행 15°, 36cm) | 0/3 | **3/3** |
| 민트(슬랩 8°) | 0/3 | 0/3 |
| 합계 | 8/30 | **13/30** |

- 합계는 켬이 낫지만 **섞여 있다**(분홍·검정은 한 번씩 줄었다). 씨앗 3번이라 한두 번의 차는 흔들림 안이다.
- 빨강(42cm)은 켬에서도 0/3: 셋째·넷째 손에서 45~52cm 모자람 — 발판이 40cm 간격이라 발을 올리지 못해 몸이 덜 올라간다(사다리 45cm와 같은 까닭으로 보인다. 걸음마다 따라가 확인하지는 않았다).
- 리드 코스는 한 번씩만: 주황(12m)은 5번째 손에서 44cm 모자람(앞 판에서는 완등했다 — 한 번의 결과라 무엇 때문인지 가르지 못했다), 하양(40cm 간격)은 16번째 손(약 7m)까지 감(앞 판: 4번째).

## 2. 기운 벽

- **만드는 방식**: 엔진의 지형은 축에 나란한 상자뿐이다. 기운 면을 **높이 15cm의 얇은 벽 조각을 계단처럼 쌓아** 만들었다(조각마다 15°면 4cm, 8°면 2.1cm 어긋남). 그림은 조각들의 가운데를 지나는 매끈한 면이다 — **물리와 그림이 2cm 안에서 다르다**(계단 근사).
- 조각의 윗모서리는 잡히지 않고 윗면은 디딜 수 없다(발은 발판을 디디거나 면에 댄다).
- **오버행 15°**(오른쪽 벽, 폭 4m, 높이 4.5m): 연두(보통, 큰 홀드 27cm 간격), 갈색(어려움, 36cm 간격). **슬랩 8°**(왼쪽 벽, 폭 3.2m): 민트(쉬움).
- 오버행 규칙 하나: 오버행 면의 홀드를 잡으면 몸의 기준 자리는 그 손보다 12cm는 벽에서 떨어져 있다(`OVER_OUT`, `OLDOVEROUT`). 전에는 몸이 디딘 발판 위로 가서(오버행에서는 발판이 손보다 40cm 안쪽) 어깨가 홀드 밑으로 들어가 팔이 걸렸다. 곧은 벽의 홀드에는 걸지 않는다.
- 상자가 606개가 되어, 계산에 넘기는 범위를 몸 둘레 3.4m(위 4.6m·아래 2m)로 줄였다.

### 결과(위 표)

- 오버행: 갈색은 누르기 켬에서 3/3, 연두는 1/3("팔이 턱에 걸려" — 위 홀드일수록 더 튀어나와 팔이 그 밑을 지나야 한다).
- **슬랩은 대충 겨누면 시작부터 실패한다(0/3, "몸에 막혀 닿지 않음")**. 정확히 겨눈 한 번은 완등했다(58초). 슬랩에서는 발치가 나와 있어 선 몸이 시작 홀드에서 멀고, 손이 가슴 앞을 돌아가다 제 몸에 걸린다. 곧게 선 몸이 벽 쪽으로 기울지 않는 것이 뿌리로 보인다(확인하지 않음).
- 하지 못한 것: 더 가파른 오버행(지붕), 기운 면의 큰 볼륨, 기운 면에 맞춘 몸 자세(몸은 여전히 세로 벽을 기준으로 선다), 슬랩에서 마찰로 서기(면에 대는 발은 세로 벽과 같은 마찰).

## 4. 다음 (개발 쪽 의견)

1. **누르는 손·오버행 자세를 그림으로 확인**하고 손 모양(손바닥을 윗면에)을 넣기 — 지금은 힘과 자리만이다.
2. 초록·보라의 끔 결과가 앞 판보다 나빠진 까닭 가르기(봇의 시작 손 간격 / 계산 범위 3.4m).
3. 발 올리기: 40cm 넘는 발 간격에서 "다리가 그렇게는 올라가지 않음" — 빨강·사다리 45cm가 여기서 막힌다.
4. 슬랩에서 몸이 벽 쪽으로 기울기, 오버행에서 위 홀드 밑으로 팔이 지나는 길.
5. 기운 면을 엔진이 직접 다루기(계단 근사 대신) — 벽을 외부 도구에서 만들려면 이것이 먼저다.
