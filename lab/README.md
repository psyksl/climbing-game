# 등반 조작 실험실 (실험 빌드 v0.2)

손발을 직접 움직여 잡고, 매달려 흔들고, 발로 밀어 뛰고, 한 손으로 잡은 뒤 안정시키는 조작을 짧게 반복 시험하는 공간입니다.
원본(`../original/01_climb.html`)은 그대로 두었고, 이 폴더가 작업 사본입니다.

## 실행

- `climb_lab.html`을 브라우저로 엽니다. 설치·빌드 없이 한 파일로 실행됩니다(마우스 + 키보드).
- 자동 시연: 주소 뒤에 `?auto=swing` / `jump` / `jug` / `top` / `early` / `late` / `all`.
- 소스를 고친 뒤 다시 묶기: `node build.js`
- 자동 시험: `node test/run.js` (자세히 `-v`), 타이밍 여유: `node test/tolerance.js`, 녹화: `node test/record.js`(Playwright 필요)

## 조작

| 입력 | 동작 |
|---|---|
| 좌클릭(또는 Q) 누르고 있기 | 왼손이 잡은 곳을 놓고 커서를 따라간다 |
| 우클릭(또는 E) 누르고 있기 | 오른손이 커서를 따라간다 |
| A / D 누르고 있기 | 왼발 / 오른발이 커서를 따라간다 |
| 버튼·키를 떼는 순간 | 손: 닿아 있는 턱을 잡는다. 발: 닿아 있는 면을 디딘다. 닿은 곳이 없으면 허공 |
| 스페이스(또는 왼쪽 Shift, W) 누르고 있기 | 붙어 있는 팔다리로 몸을 커서 쪽으로 당기고 민다. 발을 디딘 채 위로 향하면 도약 |
| R | 같은 시작 자세로 즉시 다시 |
| 1 / 2 / 3 / 4 | 시작 자세: 두 손 매달리기 / 한 손 매달리기 / 발판 위 웅크리기 / 건너편 한 손 |
| T | 절반 속도(연습용) |

- **붙잡은 상태는 키 없이 유지됩니다.** 누르고 있어야 하는 것은 "지금 움직이는 손발"과 "힘을 주는 순간"뿐입니다.
- **여러 팔다리 동시 조작**: 누른 손발이 모두 같은 커서를 향합니다. 두 손을 함께 누르면 두 손이 동시에 떨어져 뻗습니다(도약).
- 스페이스로 당긴 팔 길이·편 다리 길이는 손을 떼도 유지됩니다(버티지 못할 힘이 걸리면 그만큼 늘어납니다).
- 화면 표시: 초록 고리 = 지금 떼면 붙는다. 흰 테두리 = 붙어 있음. 노랑·빨강 테두리 = 미끄러지기 직전. 흰 원 = 그 팔다리가 닿는 범위. 반투명 = 힘이 빠진 손발.

### 필수 동작 해 보기

1. **한 손 매달려 흔들기**: `2`로 시작 → A·D를 누른 채 커서를 좌우로 리듬 맞춰 움직인다(몸이 오른쪽에 있을 때 다리는 왼쪽으로).
2. **발로 밀어 도약**: `3`으로 시작 → 스페이스를 누른 채 커서를 가슴 오른쪽 아래에 두어 웅크리고 → 커서를 오른쪽 위로 옮기며 **두 마우스 버튼을 함께 눌러** 손을 놓는다.
3. **이동 중 한 손 잡기**: 날아가는 동안 버튼을 누른 채 커서를 건너편 턱 위에 두고, 초록 고리가 뜨는 순간 뗀다.
4. **안정시키기**: 다른 손 버튼을 눌러 턱 위로 옮긴 뒤 떼고, D를 눌러 발을 발판 위에 놓고 뗀다.
5. **다른 방법**: 큰 반동으로 바로 건너기 / 발판에서 뛰기 / 작은 반동으로 가운데 저그를 잡고 당겨 올라 손 옮기기. 그 밖의 방법도 물리적으로 되면 됩니다.

목표는 위쪽 금색 턱을 두 손으로 잡는 것입니다.

## 물리 구조(요약)

- 몸은 가슴·엉덩이·양손·양발 6개 질점입니다. 몸통은 막대, 팔다리는 최대 길이가 있는 줄이며 근육 힘에는 상한이 있습니다.
- 근육은 두 질점 사이에 크기가 같고 방향이 반대인 힘으로만 작용합니다. 공중에서는 입력을 해도 운동량과 각운동량이 보존됩니다.
- 잡은 손은 그 점에 고정되고 몸이 그 점을 중심으로 돕니다. 잡거나 놓아도 속도는 그대로 이어집니다.
- 디딘 발은 마찰 접촉입니다. 다리가 누르는 방향이 면에서 약 45° 넘게 기울면 미끄러집니다. 다리는 밀기만 합니다.
- 손은 면 종류마다 버티는 방향 한계가 있습니다: 깊은 턱 105°, 턱 75°, 둥근 면 40°, 저그는 모든 방향. 한계를 넘겨 당기면 미끄러집니다. 확률 요소는 없습니다.
- 손발은 벽 앞을 지나다니다가 떼는 순간에만 지형과 맞닿습니다(정면에서 본 벽).
- 960Hz 고정 스텝, 위치 기반 구속. 같은 입력이면 항상 같은 결과가 나옵니다.

## 원본에서 바뀐 것

- 폐기: 손발 선택 → 가능한 홀드 표시 → 클릭 자동 이동, 자세 풀이기(`solve`/`canReach`), "세 점 지지" 안정 규칙, 한 손 버티기 타이머, 고정 홀드 목록.
- 재사용: 공통 엔진(고정 스텝 루프, 입력, 효과음, 그리기 도구), 두 마디 팔다리 그리기, 좌우 색 구분, 매트와 즉시 재시작.
- 새로 작성: `src/physics.js`(물리 전체), `src/game.js`(입력·화면), `src/bots.js`(자동 조작기), `test/`.

## 자동 시험 결과와 재미 평가는 별개입니다

**자동 시험으로 확인한 것** (`node test/run.js`, 12개 항목 모두 통과)

- 네 가지 시작 자세가 입력 없이 가만히 유지된다.
- 한 손으로 매달려 다리 반동만으로 흔들림이 커진다(약 23° → 70°).
- 공중에서 수평 운동량이 보존된다.
- 세 가지 방법과 마무리(목표 턱)가 사람과 같은 입력만으로 끝까지 성립한다.
- 실패 예 두 가지는 실제로 떨어진다.
- 브라우저에서 실제 마우스·키 입력이 손발 상태로 이어지고, 여섯 가지 시연이 같은 결과로 재현된다.

**확인하지 못한 것**

- 사람이 직접 했을 때의 손맛, 난이도, 재미. 자동 조작기는 상태를 읽고 정확한 시점에 입력하므로 "사람도 할 만하다"의 증거가 아닙니다. 이 빌드는 사람 손으로 플레이해 보지 못했습니다.

## 알려진 문제

- **도약 때 손 놓는 타이밍이 빡빡합니다.** 미는 순간부터 약 0.04초 안에 손을 놓아야 하고, 0.06초 이후는 실패했습니다. 사람에게는 사실상 "동시에 누르기"입니다.
- **스윙으로 건너는 여유가 좁습니다.** 진폭 55°에서는 놓는 각도 45~65°가 성공했지만, 진폭 40°에서는 45~50°만 성공했습니다. 반동을 그만큼 키우는 데 자동 조작기로 약 4~6초가 걸립니다.
- 다리 반동의 리듬(몸 반대쪽으로 다리 보내기)이 직관적인지 검증되지 않았습니다.
- 손발이 붙어 있는 동안에는 팔다리를 휘두르는 반작용이 몸통 회전으로 돌아가지 않습니다. 완전히 물리적으로 하면 반동이 거의 커지지 않아 택한 타협이며, 공중에서는 정확히 보존됩니다.
- 누른 손발이 모두 한 커서를 향하므로 두 팔다리를 서로 다른 곳으로 동시에 보낼 수 없습니다.
- 팔다리 중간(팔꿈치·무릎)과 몸통은 지형과 충돌하지 않고, 가슴이 잡은 손을 통과할 수 있습니다.
- 다리 관절 범위는 뻗을 때만 제한합니다. 디딘 뒤에는 어색한 각도가 나올 수 있습니다.
- 한 화면 고정 카메라입니다. 맵이 커지면 따라가는 카메라가 필요합니다.
- 터치·게임패드는 지원하지 않습니다. 체력·장비·재화·추가 스테이지는 범위에서 뺐습니다.
- 둥근 면은 놓여 있지만 자동 시험에 포함되지 않았습니다.
