# 등반 조작 실험실 v0.7.2 · 조작표

`climb_lab.html`을 브라우저로 열면 **D안**으로 시작합니다. **Tab**으로 다른 방식(A·B·C안)과 바꿀 수 있고, 화면 왼쪽 위에 지금 방식의 키가 항상 표시됩니다.

## D안 · 의도 조작 (v0.6 기본)

어느 손발을, 어디로, 언제 던질지만 정합니다. 균형, 발 위치, 손을 놓는 순간은 게임이 채웁니다.
**모든 입력은 키 설정(Esc 또는 0)에서 바꿀 수 있습니다.** 아래는 기본값입니다.

### 손 선택 방식 (H로 바꿈)

| | 1번 방식 (기본) | 2번 방식 |
|---|---|---|
| 손 입력 | **좌클릭·Q** = 왼손, **우클릭·E** = 오른손 | **좌클릭·Q** = 추천 손, **우클릭·E** = 다른 손 |
| 누르기 전 표시 | 커서 왼쪽·오른쪽에 "좌클릭 → 왼손 보내기" 같은 표시. 같은 표시가 그 손 위에도 붙음 | 커서 위에 "좌클릭 → 오른손 보내기 (추천)". 추천 손이 깜빡이는 고리로 강조됨 |
| 바뀌는 때 | 바뀌지 않음 | 다른 손이 확실히 나을 때만 바뀜(커서를 조금 흔들어도 그대로). 누르는 순간 그 손으로 확정 |

### 동작

| 하려는 것 | 기본 입력 | 게임이 채우는 것 |
|---|---|---|
| 조준 | 마우스, 또는 **방향키**(누르고 있으면 점점 빨라짐, **왼Ctrl**을 누른 채면 천천히) | |
| 손 보내기 | 위의 손 입력. 누르고 있을 필요 없음 | 손을 떼기 전에 몸을 남은 손 쪽으로 옮김(최대 0.2초). **초록 구간**에 닿으면 잡음 |
| 발 직접 | **Shift**를 누른 채 손 입력 = 같은 쪽 발(2번 방식이면 추천 발) | 겨눈 면에 닿으면 디딤 |
| 발 자동 | Shift를 누르지 않으면 발은 자동 | 디딜 곳 고르기, 다리 꼬지 않기 |
| 몸통 옮기기 | **W** 위 · **S** 아래 · **A** 왼쪽 · **D** 오른쪽. 두 키를 함께 누르면 대각선. 누르는 동안 움직이고 떼면 그 자리에서 버팀 | 붙은 팔다리로 당기고 밀어 옮김. 팔다리 길이 한계, 손이 미끄러질 각도(한계 −10°) 너머로는 가지 않고 "더 못 감 — 팔 길이 한계"처럼 이유를 보여 줌 |
| 뛰기 | **Space를 누르고 있기** = 힘 모으기, **떼기** = 커서 쪽으로 던지기 | |
| 뛸 때 놓을 손 | Space를 **누른 채** 손 입력 = 그 손에 주황 고리 "도약 때 놓음". 같은 입력을 한 번 더 = 지정 취소 | 던지는 동안 알맞은 순간에 놓고, 커서 쪽으로 뻗어 닿으면 잡음 |
| 모으는 중 몸 싣기 | Space를 누른 채 **A/D** = 엉덩이를 왼쪽/오른쪽에 싣기(최대 40px, 팔다리 한계까지). A로 목표 반대쪽에 실었다가 D로 돌아오며, 엉덩이가 목표 쪽으로 움직이기 시작하고 0.05~0.15초 뒤에 Space를 떼면 멀리 간다. 노란 화살표 = 엉덩이가 움직이는 방향 | |
| 모으는 중 표시 | 주황 고리 = 도약 때 놓을 손, 하늘색 고리 = 이동 중인 손. 글로 된 설명은 왼쪽 아래 상태 칸 | |
| 취소 | **X**: 모으는 중이면 놓을 손 지정을 모두 취소, 평소에는 들고 있는 손발을 늘어뜨림 | |
| 반동 | 놓을 손을 지정하지 않고 Space를 짧게 눌렀다 떼기 | 놓을 손이 없으면 뛰지 않고 몸만 실음 |

### 잡기 보조 (B로 범위 바꿈, V로 켜고 끔)

- **커서 근처(기본)**: 커서에서 가장 가까운 잡을 곳 주변 ±28px만 초록으로 표시되고, 손이 그 구간에 닿아야 잡힙니다. 구간 밖에 닿으면 "겨눈 구간 밖에 닿음 (N px 벗어남)"이 뜹니다.
- **턱 전체**: 겨눈 턱 어디에 닿아도 잡힙니다(v0.5 방식).
- 커서 근처 방식에서는 **멀리 겨눌수록 길게, 가까이 겨눌수록 짧게** 모아야 합니다. 가까운 끝을 겨누고 길게 모으면 손이 구간을 지나칩니다.

### 키 설정 화면 (Esc 또는 0)

- 동작마다 두 칸(주·보조)이 있습니다. 칸을 클릭하거나 방향키로 고르고 Enter → 새 키나 마우스 버튼(좌·휠·우·옆 버튼)을 누릅니다.
- Delete는 비우기, Esc는 입력받기 취소 또는 닫기입니다.
- 맨 위 줄을 클릭하면 1번·2번 방식의 손 입력을 각각 볼 수 있습니다.
- 같은 입력이 두 동작에 쓰이면 빨간 칸과 주의 문구가 뜹니다. 그대로 두면 두 동작이 함께 실행됩니다.
- **기본값 복원** 버튼이 있습니다. 바꾸면 바로 저장되고 새로고침해도 남습니다.

### 기타

- **L**: 플레이 기록. 손 선택 헷갈림 추정, 미끄러져 놓침, 입력 후 반응 지연을 보여 줍니다.
- 화면 오른쪽 아래에 방금 쓴 입력이 잠깐 표시됩니다.

### 해 볼 것

1. **오른손으로 매달린 채 왼발 옮기기**: `2`로 시작해 기다리면 발이 알아서 딛습니다. 직접 하려면 F로 자동 발을 끄고 Shift+좌클릭으로 발판 윗면을 누릅니다.
2. **두 손으로 뛰어 건너편 잡기**: `3`으로 시작합니다.
   1. 커서를 건너편 턱 **가운데**에 둡니다.
   2. Space를 누른 채 좌클릭과 우클릭으로 두 손에 주황 고리를 띄웁니다.
   3. Space를 0.3초쯤 더 누르고 있다가 뗍니다.
   - 멀리 겨눌수록 오래 모읍니다. 턱 왼쪽 끝은 0.1~0.4초, 가운데는 0.5초 이상이 맞습니다.
   - 가까운 곳으로 짧게 뛸 때는 Space를 누르자마자 좌·우클릭을 빠르게 이어 눌러야 합니다. 연습할 부분입니다.
3. **세 점으로 버티다 오른손으로 멀리 잡기**: `3`으로 시작합니다.
   1. 커서를 건너편 턱에 두고 우클릭합니다. 오른손이 뻗어 기다립니다.
   2. Space를 누른 채 좌클릭해서 왼손을 지정합니다.
   3. Space를 뗍니다.
4. **턱 위로 올라서기 (W)**: 두 손으로 건너편 턱에 매달린 상태에서 W를 누르고 있으면 턱걸이처럼 당겨 올라가고, 가슴이 손보다 높아지면 팔로 눌러 턱 위로 올라섭니다. 그 자세에서 발이 턱 윗면을 찾아 딛습니다(자동 발 또는 Shift+클릭). 그다음 손을 위쪽 목표 턱으로 보냅니다.
5. **키보드만**: 마우스에서 손을 떼고 방향키로 조준점을 옮깁니다. Space를 누른 채 Q·E로 두 손을 지정하고 Space를 뗍니다.
6. **2번 방식**: H를 누르고 커서를 움직여 추천 손이 어떻게 바뀌는지 봅니다.

## A안 · 집기와 붙이기 분리 (v0.4 기본, 마우스 + 왼손 키보드)

| 하려는 것 | 입력 |
|---|---|
| 손발 하나를 떼어 집기 | **Q** 왼손 · **E** 오른손 · **A** 왼발 · **D** 오른발 — 한 번 누르면 떼어져 커서를 따라옴(누르고 있지 않음) |
| 집은 손발을 붙이기 | **좌클릭** — 초록 고리가 보일 때. 닿은 곳이 없으면 붙지 않고 계속 들고 있음 |
| 붙이지 않고 힘 빼기 | **우클릭**, 또는 같은 손발 키를 다시 |
| 다리로 반동 주기 | **Z** / **C** 누르고 있기 = 다리를 왼쪽 / 오른쪽으로, **X** = 다리 접기. 놓으면 힘이 빠짐(디뎌지지 않음) |
| 붙은 팔다리로 밀기·당기기 | **Space** 누르고 있기 (커서 방향) |

키 배치는 몸 모양 그대로입니다: 윗줄 Q·E가 손, 가운뎃줄 A·D가 발, 왼쪽 열이 왼쪽 팔다리.

## B안 · 키보드 좌우 분담 (GPT 제안, 키보드만)

| 하려는 것 | 왼손(왼쪽 팔다리) | 오른손(오른쪽 팔다리) |
|---|---|---|
| 움직일 팔·발 고르기(떼어짐) | **Q** 왼손 · **Z** 왼발 | **U** 오른손 · **M** 오른발 |
| 끝점 움직이기 | **W A S D** | **I J K L** |
| 접촉 시도 | 같은 키(Q·Z) 다시 | 같은 키(U·M) 다시 |
| 붙이지 않고 힘 빼기 | **E** | **O** |
| 밀기·당기기 | **Space** — 누르고 있는 방향키 쪽, 없으면 위 | |

## C안 · v0.3 방식

좌클릭·우클릭(또는 Q·E)과 A·D를 누르고 있는 동안 커서를 따라오고, 떼는 순간 붙습니다. Space는 같습니다.

| Esc 또는 0 | D안: 키 설정 화면. A·B·C안: 지금 방식의 키를 순서대로 다시 지정 |

## 첫 시험 세 가지 (v0.4, A·B안)

1. **오른손으로 매달린 채 왼발 옮기기** — `2`로 시작. A안: A → 커서를 왼쪽 아래 발판 윗면에 → 좌클릭. B안: Z → S·A로 이동 → Z.
2. **양쪽을 서로 다른 방향으로** — B안: Q와 M을 고른 뒤 A와 L을 함께. A안은 커서가 하나라 동시에는 안 되고 차례로 옮깁니다.
3. **발로 밀어 한 손으로 건너편 잡기** — `3`으로 시작. A안: 커서를 건너편 턱 왼쪽 끝에 두고 Space + Q·E → 초록 고리에서 좌클릭. B안: Space + L·I(오른쪽 위) → Q·U → 방향키로 손을 턱으로 → Q 또는 U.
