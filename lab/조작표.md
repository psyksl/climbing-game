# 등반 조작 실험실 v0.11.1 · 조작표

`climb_lab.html`을 브라우저로 열면 **D안**으로 시작합니다. **Tab**으로 다른 방식(A·B·C안)과 바꿀 수 있고, 화면 왼쪽 위에 지금 방식의 키가 항상 표시됩니다.

## D안 · 의도 조작 (v0.6 기본)

어느 손발을, 어디로, 언제 던질지만 정합니다. 균형, 발 위치, 손을 놓는 순간은 게임이 채웁니다.
**모든 입력은 키 설정(Esc 또는 0)에서 바꿀 수 있습니다.** 아래는 기본값입니다.

### 손 선택 방식 (H로 바꿈)

| | 1번 방식 (기본) | 2번 방식 |
|---|---|---|
| 손 입력 | **좌클릭·Q** = 왼손, **우클릭·E** = 오른손 | **좌클릭·Q** = 추천 손, **우클릭·E** = 다른 손 |
| 누르기 전 표시 | 커서 왼쪽·오른쪽에 "좌클릭 → 왼손 보내기" 같은 표시. 같은 표시가 그 손 위에도 붙음 | 커서 위에 "좌클릭 → 오른손 보내기 (추천)". 추천 손이 깜빡이는 고리로 강조됨 |
| 바뀌는 때 | 바뀌지 않음 | 다른 손이 확실히 나을 때만 바뀜(커서를 조금 흔들어도 그대로). 누르는 순간 그 손으로 확정 |

### 동작

| 하려는 것 | 기본 입력 | 게임이 채우는 것 |
|---|---|---|
| 조준 | 마우스, 또는 **방향키**(누르고 있으면 점점 빨라짐, **왼Ctrl**을 누른 채면 천천히) | |
| 손 보내기 | 위의 손 입력. 누르고 있을 필요 없음 | 손을 떼기 전에 몸을 남은 손 쪽으로 옮김(최대 0.2초). **초록 구간**에 닿으면 잡음 |
| 발 직접 | **Shift**를 누른 채 손 입력 = 같은 쪽 발(2번 방식이면 추천 발) | 겨눈 면에 닿으면 디딤 |
| 발 자동 | Shift를 누르지 않으면 발은 자동 | 디딜 곳 고르기, 다리 꼬지 않기 |
| 몸통 옮기기 | **W** 위 · **S** 아래 · **A** 왼쪽 · **D** 오른쪽. 두 키를 함께 누르면 대각선. 누르는 동안 움직이고 떼면 그 자리에서 버팀 | 붙은 팔다리로 당기고 밀어 옮김. 팔다리 길이 한계, 손이 미끄러질 각도(한계 −10°) 너머로는 가지 않고 "더 못 감 — 팔 길이 한계"처럼 이유를 보여 줌 |
| 뛰기 | **Space를 누르고 있기** = 힘 모으기, **떼기** = 커서 쪽으로 던지기 | |
| 뛸 때 놓을 손 | Space를 **누른 채** 손 입력 = 그 손에 주황 고리 "도약 때 놓음". 같은 입력을 한 번 더 = 지정 취소 | 던지는 동안 알맞은 순간에 놓고, 커서 쪽으로 뻗어 닿으면 잡음 |
| 모으는 중 몸 싣기 | Space를 누른 채 **A/D** = 엉덩이를 왼쪽/오른쪽에 싣기(최대 40px, 팔다리 한계까지). A로 목표 반대쪽에 실었다가 D로 돌아오며, 엉덩이가 목표 쪽으로 움직이기 시작하고 0.05~0.15초 뒤에 Space를 떼면 멀리 간다. 노란 화살표 = 엉덩이가 움직이는 방향 | |
| 온몸 도약 (관절 몸) | Space를 **떼는 순간 W**를 누르고 있으면 놓을 손이 바로 놓이지 않고 팔로 몸을 끌어 올린 뒤 놓는다(다리 + 팔). 모으는 동안 **S** = 더 깊이 가라앉기(여유가 있을 때만) | |
| 한 팔 도약 (관절 몸) | 한 손을 먼저 보내 두고 뛰면 그 손으로만 잡는다(놓는 손은 따라 뻗지 않음). 한 팔이 두 팔보다 조금 더 멀리 닿는다 | |
| 팔 힘으로 올라가기 | 두 손으로 턱을 잡고 **W**를 누르고 있으면 허리가 턱 높이에 올 때까지 올라가 팔로 버틴다. 손으로 잡은 턱 위에 발을 올려 서지는 않는다 | |
| 모으는 중 표시 | 주황 고리 = 도약 때 놓을 손, 하늘색 고리 = 이동 중인 손. 글로 된 설명은 왼쪽 아래 상태 칸 | |
| 취소 | **X**: 모으는 중이면 놓을 손 지정을 모두 취소, 평소에는 들고 있는 손발을 늘어뜨림 | |
| 반동 | 놓을 손을 지정하지 않고 Space를 짧게 눌렀다 떼기 | 놓을 손이 없으면 뛰지 않고 몸만 실음 |

### 잡기 보조 (B로 범위 바꿈, V로 켜고 끔)

- **커서 근처(기본)**: 커서에서 가장 가까운 잡을 곳 주변 ±28px만 초록으로 표시되고, 손이 그 구간에 닿아야 잡힙니다. 구간 밖에 닿으면 "겨눈 구간 밖에 닿음 (N px 벗어남)"이 뜹니다.
- **턱 전체**: 겨눈 턱 어디에 닿아도 잡힙니다(v0.5 방식).
- 커서 근처 방식에서는 **멀리 겨눌수록 길게, 가까이 겨눌수록 짧게** 모아야 합니다. 가까운 끝을 겨누고 길게 모으면 손이 구간을 지나칩니다.

### 키 설정 화면 (Esc 또는 0)

- 동작마다 두 칸(주·보조)이 있습니다. 칸을 클릭하거나 방향키로 고르고 Enter → 새 키나 마우스 버튼(좌·휠·우·옆 버튼)을 누릅니다.
- Delete는 비우기, Esc는 입력받기 취소 또는 닫기입니다.
- 맨 위 줄을 클릭하면 1번·2번 방식의 손 입력을 각각 볼 수 있습니다.
- 같은 입력이 두 동작에 쓰이면 빨간 칸과 주의 문구가 뜹니다. 그대로 두면 두 동작이 함께 실행됩니다.
- **기본값 복원** 버튼이 있습니다. 바꾸면 바로 저장되고 새로고침해도 남습니다.

### 기타

- **L**: 플레이 기록. 손 선택 헷갈림 추정, 미끄러져 놓침, 입력 후 반응 지연을 보여 줍니다.
- 화면 오른쪽 아래에 방금 쓴 입력이 잠깐 표시됩니다.

### 해 볼 것

1. **오른손으로 매달린 채 왼발 옮기기**: `2`로 시작해 기다리면 발이 알아서 딛습니다. 직접 하려면 F로 자동 발을 끄고 Shift+좌클릭으로 발판 윗면을 누릅니다.
2. **두 손으로 뛰어 건너편 잡기**: `3`으로 시작합니다.
   1. 커서를 건너편 턱 **가운데**에 둡니다.
   2. Space를 누른 채 좌클릭과 우클릭으로 두 손에 주황 고리를 띄웁니다.
   3. Space를 0.3초쯤 더 누르고 있다가 뗍니다.
   - 멀리 겨눌수록 오래 모읍니다. 턱 왼쪽 끝은 0.1~0.4초, 가운데는 0.5초 이상이 맞습니다.
   - 가까운 곳으로 짧게 뛸 때는 Space를 누르자마자 좌·우클릭을 빠르게 이어 눌러야 합니다. 연습할 부분입니다.
3. **세 점으로 버티다 오른손으로 멀리 잡기**: `3`으로 시작합니다.
   1. 커서를 건너편 턱에 두고 우클릭합니다. 오른손이 뻗어 기다립니다.
   2. Space를 누른 채 좌클릭해서 왼손을 지정합니다.
   3. Space를 뗍니다.
4. **턱 위로 올라서기 (W)**: 두 손으로 건너편 턱에 매달린 상태에서 W를 누르고 있으면 턱걸이처럼 당겨 올라가고, 가슴이 손보다 높아지면 팔로 눌러 턱 위로 올라섭니다. 그 자세에서 발이 턱 윗면을 찾아 딛습니다(자동 발 또는 Shift+클릭). 그다음 손을 위쪽 목표 턱으로 보냅니다.
5. **키보드만**: 마우스에서 손을 떼고 방향키로 조준점을 옮깁니다. Space를 누른 채 Q·E로 두 손을 지정하고 Space를 뗍니다.
6. **2번 방식**: H를 누르고 커서를 움직여 추천 손이 어떻게 바뀌는지 봅니다.

## A안 · 집기와 붙이기 분리 (v0.4 기본, 마우스 + 왼손 키보드)

| 하려는 것 | 입력 |
|---|---|
| 손발 하나를 떼어 집기 | **Q** 왼손 · **E** 오른손 · **A** 왼발 · **D** 오른발 — 한 번 누르면 떼어져 커서를 따라옴(누르고 있지 않음) |
| 집은 손발을 붙이기 | **좌클릭** — 초록 고리가 보일 때. 닿은 곳이 없으면 붙지 않고 계속 들고 있음 |
| 붙이지 않고 힘 빼기 | **우클릭**, 또는 같은 손발 키를 다시 |
| 다리로 반동 주기 | **Z** / **C** 누르고 있기 = 다리를 왼쪽 / 오른쪽으로, **X** = 다리 접기. 놓으면 힘이 빠짐(디뎌지지 않음) |
| 붙은 팔다리로 밀기·당기기 | **Space** 누르고 있기 (커서 방향) |

키 배치는 몸 모양 그대로입니다: 윗줄 Q·E가 손, 가운뎃줄 A·D가 발, 왼쪽 열이 왼쪽 팔다리.

## B안 · 키보드 좌우 분담 (GPT 제안, 키보드만)

| 하려는 것 | 왼손(왼쪽 팔다리) | 오른손(오른쪽 팔다리) |
|---|---|---|
| 움직일 팔·발 고르기(떼어짐) | **Q** 왼손 · **Z** 왼발 | **U** 오른손 · **M** 오른발 |
| 끝점 움직이기 | **W A S D** | **I J K L** |
| 접촉 시도 | 같은 키(Q·Z) 다시 | 같은 키(U·M) 다시 |
| 붙이지 않고 힘 빼기 | **E** | **O** |
| 밀기·당기기 | **Space** — 누르고 있는 방향키 쪽, 없으면 위 | |

## C안 · v0.3 방식

좌클릭·우클릭(또는 Q·E)과 A·D를 누르고 있는 동안 커서를 따라오고, 떼는 순간 붙습니다. Space는 같습니다.

## 첫 시험 세 가지 (v0.4, A·B안)

1. **오른손으로 매달린 채 왼발 옮기기** — `2`로 시작. A안: A → 커서를 왼쪽 아래 발판 윗면에 → 좌클릭. B안: Z → S·A로 이동 → Z.
2. **양쪽을 서로 다른 방향으로** — B안: Q와 M을 고른 뒤 A와 L을 함께. A안은 커서가 하나라 동시에는 안 되고 차례로 옮깁니다.
3. **발로 밀어 한 손으로 건너편 잡기** — `3`으로 시작. A안: 커서를 건너편 턱 왼쪽 끝에 두고 Space + Q·E → 초록 고리에서 좌클릭. B안: Space + L·I(오른쪽 위) → Q·U → 방향키로 손을 턱으로 → Q 또는 U.

## 연습 과제와 시범 (v0.11.1)

| 키 | 하는 일 |
|---|---|
| **O** | 다음 연습 과제(1 → 6 → 자유 연습). 과제마다 시작 자세가 정해지고, 필요한 연습용 턱이 벽에 생긴다. 몸은 관절 몸으로 바뀐다 |
| **P** | 지금 과제의 시범 보기. 시범이 끝나면 같은 자세로 돌아가 직접 해 볼 차례가 된다 |
| **U** | 시범 유령 켬·끔(기본 켬) |
| **T** | 입력 비교 차트: 작게 → 펼침 → 끔 |
| **,** / **.** | 입력 비교 차트의 시간축을 앞·뒤로 |
| **[** / **]** / **\\** | 시간축 축소 / 확대 / 전체 보기 |
| **Y** | 리플레이 보기·닫기(시도가 끝난 뒤. 하는 중에 누르면 거기서 끝내고 본다) |
| R | 같은 자세로 다시 |

- **화면 배치**: 과제 중에는 위쪽 조작 설명 칸을 숨깁니다(벽과 목표 턱을 가리지 않게). 오른쪽에 과제 카드(이름·목표·요령), 화면 아래에 입력 타임라인 띠가 나옵니다. 조작 설명은 자유 연습 화면에 있습니다(O로 과제를 끝까지 넘기면 자유 연습).
- **시도가 끝나면**(v0.11.0): 떨어지거나 성공해도 바로 처음으로 돌아가지 않고 결과 화면에서 멈춥니다. **다시하기(R)**, **리플레이(Y)**, (과제에서는) 다음 과제(O)를 키나 마우스로 누릅니다.
- **리플레이**: 내가 한 플레이를 그대로 다시 봅니다. 0초(첫 입력)부터 재생합니다.

  | 키 | 하는 일 |
  |---|---|
  | Space | 재생·멈춤(끝에서 누르면 처음부터) |
  | ← / → | 0.05초 뒤로·앞으로(누르고 있으면 계속) |
  | ↓ | 재생 속도 1 → 0.5 → 0.25배 |
  | 차트의 시간축을 누르거나 끌기 | 그 시각으로 감. 재생하면 거기서부터 |
  | Y | 닫기(결과 화면으로) |
  | R | 다시하기 |

- **차트의 시작 표식**(v0.11.1): 입력마다 시작점 왼쪽에 그때 실제로 누른 키가 작은 표식으로 붙습니다. 표식의 크기는 누른 시간과 상관없고, 누른 시간은 막대 길이로 봅니다. 막대나 표식에 마우스를 올리면 시각과 누른 시간이 나옵니다. 겹치는 표식은 ×개수로 묶여 보이고 확대하면 따로 보입니다. 키를 다시 지정해도 지난 기록은 그때 누른 키로 보입니다.
- **키가 쓰이는 때**: 손발·몸·조준 = 하는 중에만 / 보조 설정 = 하는 중과 결과 화면 / 다시하기·리플레이·다음 과제·시범·차트·키 설정 = 언제나 / 리플레이 도구 = 리플레이 중에만. 쓰이는 때가 겹치는 두 동작에 같은 키를 주면 키 설정에서 빨간 칸으로 알립니다.
- **차트를 창처럼**: 차트의 머리줄을 끌면 옮겨지고, 모서리·변을 끌면 크기가 바뀝니다. [전체] [−] [+] 단추나 마우스 휠로 시간축을 조절하고, 확대했을 때는 시간축을 끌어 옮깁니다. 옮긴 차트에는 [제자리] 단추가 생깁니다.
  - 마우스가 차트나 단추 위에 있을 때의 클릭은 게임 입력이 아닙니다(손을 보내지 않음).
- **입력 비교 차트**: T로 작게 → 펼침 → 끔.
  - 줄 = 수행한 동작. 줄 머리에는 이름 없이 키캡만 나옵니다(v0.11.0). 가로가 시간이고 **0초 = 첫 입력**입니다(조준점 옮기기는 세지 않음).
  - 시범 = 윤곽선, 내 입력 = 채움. 순간 입력(손발 보내기) = 마름모, 누르고 있기 = 구간. 옆에 누른 시간과 시범과의 차이가 붙습니다.
  - **키캡의 모양은 지금 설정된 실제 입력, 색은 수행한 동작**입니다(왼손 코럴, 오른손 파랑, 모으기 노랑, 몸 옮기기 민트, 발 보라). 이번 시도에서 실제로 누른 입력이 있으면 그것을 보입니다.
  - 색은 동작을 구분할 뿐 성공·실패가 아닙니다. 성공 여부는 실제 등반 결과로 봅니다.
  - 기록이 3초보다 길면 시간축이 따라 움직이고 `,` `.`로 앞뒤를 봅니다.
- **아래 키 안내**: 왼손·오른손·왼발·오른발·모으기의 키캡과 동작 이름, 그 손발의 상태. 키를 다시 지정하면 바로 바뀌고, 누르면 키캡이 눌립니다. 발은 "발 조종 키 + 손 입력" 조합으로 나옵니다.
- **시범 유령**: 과제에서 내가 첫 입력을 하는 순간, 시범 캐릭터가 흐릿한 파란 모습으로 같은 순간(시범의 첫 입력)부터 함께 움직입니다. 내 몸이 유령과 겹쳐 있으면 시범과 같은 박자입니다. 시범(P)을 먼저 보지 않아도 나옵니다. 껐다 켜면 지금 시각에 맞는 자리로 옵니다.
- **설정**: 시범과 유령은 내 설정과 상관없이 늘 시범 기준 설정으로 움직입니다.
  - 과제에 들어오면 결과를 바꾸는 보조 설정(자동 발 F, 체중 이동 G, 닿으면 잡기 V, 잡기 범위 B, 자동 싣기 N)과 몸·벽·물리·도약 연결을 기준에 맞추고, 과제를 나가면 되돌립니다. 맞춘 것은 과제 카드에 나옵니다.
  - 손 선택 방식(H)은 그대로 둡니다. 2번 방식이면 요령의 좌클릭·우클릭은 왼손·오른손 보내기로 읽습니다.
  - 과제 안에서 보조 설정을 바꾸면 카드에 "시범 기준과 다름"이 나옵니다. 몸(−)·물리(9)·벽(8)·조작 방식(Tab)·도약 연결(7)은 과제 중에 잠깁니다.
- 과제 4·5·6은 잡아야 할 턱에 금색 테두리와 "과제 목표" 이름표가 붙습니다. 기존 벽의 "목표: 두 손으로 잡기"는 과제 중에 나오지 않습니다.
- 자유 연습에서도 타임라인이 나옵니다. 윤곽이 이전 시도, 채운 막대가 이번 시도입니다.
- 시범과 유령은 사람이 한 것이 아닙니다. 시뮬레이션에서 되는 값을 찾아 적어 둔 입력을 같은 시각에 그대로 넣는 것입니다. 사람은 반응이 늦고 조준이 흔들리므로 똑같이 되지 않는 것이 정상입니다.

### 시범 입력 시간표 (0초 = 첫 입력. 조준점 옮기기는 입력으로 세지 않는다)

**1. 팔 힘으로 허리까지 올라가기** (시작 자세 1)

- 목표: 두 손으로 잡은 턱에서 W를 누르고 있어 가슴이 턱 위로 올라가게 한다

| 시각 | 입력 |
|---|---|
| −0.50초 | 조준점을 (430, 420)로 |
| +0.00초 | W 누르기 시작 |
| +2.40초 | W 떼기 (2.40초 동안 누름) |

- W를 계속 누르고 있는다(약 2초)
- 허리가 턱 높이에 오면 팔로 버틴다. 턱 위에 올라서지는 않는다

**2. 좌우 체중 이동** (시작 자세 1)

- 목표: A로 엉덩이를 왼쪽에, D로 오른쪽에 실어 본다(두 발은 디딘 채)

| 시각 | 입력 |
|---|---|
| −0.50초 | 조준점을 (430, 420)로 |
| +0.00초 | A 누르기 시작 |
| +0.80초 | A 떼기 (0.80초 동안 누름) |
| +1.20초 | D 누르기 시작 |
| +2.50초 | D 떼기 (1.30초 동안 누름) |

- A를 누르면 다리가 펴지며 엉덩이가 왼쪽으로 빠지고 조금 들린다
- 떼면 그 자리에서 버틴다

**3. 손 교차해 옮겨 잡기** (시작 자세 1)

- 목표: 오른손을 왼손 너머 왼쪽에 잡고, 이어서 왼손을 더 왼쪽으로 옮긴다

| 시각 | 입력 |
|---|---|
| −0.50초 | 조준점을 (250, 298)로 |
| +0.00초 | 우클릭(오른손) 한 번 |
| +1.50초 | 조준점을 (210, 298)로 |
| +1.70초 | 좌클릭(왼손) 한 번 |

- 조준점을 왼손보다 왼쪽에 두고 우클릭
- 몸이 손을 따라 왼쪽으로 기운다
- 잡으면 조준점을 더 왼쪽으로 옮기고 좌클릭

**4. 세 점에서 한 손으로 뛰어 잡기** (시작 자세 3)

- 목표: 오른손을 먼저 보내고, Space를 0.5초 모았다 떼어 건너편 턱을 오른손으로 잡는다

| 시각 | 입력 |
|---|---|
| −0.40초 | 조준점을 (545, 348)로 |
| +0.00초 | 우클릭(오른손) 한 번 |
| +1.00초 | Space 누르기 시작 |
| +1.12초 | 좌클릭(왼손) 한 번 |
| +1.50초 | Space 떼기 (0.50초 동안 누름) |

- 건너편 턱을 겨누고 우클릭 → 오른손이 먼저 뻗는다
- Space를 누른 채 좌클릭 → 왼손이 "놓을 손"이 된다
- Space를 0.5초쯤에 뗀다. 덜 모으면 못 미치고 더 모으면 지나친다

**5. 한 팔로 높이 뛰어 잡기** (시작 자세 3, 연습용 턱 추가)

- 목표: 머리 위 높은 턱을 한 팔로 잡는다. 두 손을 다 놓고 뛰면 닿지 않는 높이다

| 시각 | 입력 |
|---|---|
| −0.40초 | 조준점을 (307, 108)로 |
| +0.00초 | 우클릭(오른손) 한 번 |
| +1.00초 | Space 누르기 시작 |
| +1.12초 | 좌클릭(왼손) 한 번 |
| +1.80초 | Space 떼기 (0.80초 동안 누름) |

- 높은 턱을 겨누고 우클릭 → 오른손을 먼저 올린다
- Space를 누른 채 좌클릭(왼손만 놓음), 0.8초 모았다 뗀다
- 한 팔만 뻗으면 어깨가 올라가 더 높이 닿는다

**6. 온몸 도약: 떼면서 W** (시작 자세 3, 연습용 턱 추가)

- 목표: 더 높은 턱. Space를 떼는 순간 W를 누르고 있어 팔로도 몸을 끌어 올린다

| 시각 | 입력 |
|---|---|
| −0.40초 | 조준점을 (307, 98)로 |
| +0.00초 | 우클릭(오른손) 한 번 |
| +1.00초 | Space 누르기 시작 |
| +1.12초 | 좌클릭(왼손) 한 번 |
| +1.77초 | W 누르기 시작 |
| +1.80초 | Space 떼기 (0.80초 동안 누름) |
| +2.40초 | W 떼기 (0.63초 동안 누름) |

- 한 팔 도약과 같은 순서로 준비한다
- Space를 떼기 직전에 W를 누르고, 뜬 뒤까지 누르고 있는다
- 왼팔이 끝까지 당기고 밀어 준 뒤 놓인다
